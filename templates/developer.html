Project information

HealthcareDL

HealthcareDL is an educational deep learning project built with Python, PyTorch, and Flask. The project repository contains the training pipeline, dataset audit, model artifacts, notebook, and automated tests.

Reproducibility

The README explains installation, training, evaluation, and local startup. Exported models include feature and category mappings so that training and serving use the same schema. The evaluation report records random seeds, package versions, data hashes, and split membership.

Contributions

Useful improvements include establishing dataset provenance, obtaining independent evaluation data, and reviewing educational content with qualified healthcare professionals. Attribution and contribution history are available in the repository's Git history.
