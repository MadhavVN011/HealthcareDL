About the project

Learning from symptom patterns

This project demonstrates a deep neural network that classifies binary symptom patterns into 41 dataset categories. Its purpose is to study data preparation, neural network training, evaluation, and serving predictions through a web application.

What the results mean

A dataset match describes what the model learned from a small collection of example patterns. It is not a medical diagnosis. Similar symptoms can have different causes, and many conditions are absent from this dataset.

Limits of the data

The supplied training file contains 4,920 rows but only 304 unique symptom patterns. The table has been matched to a public publisher release, and its declared license is documented. Original clinical collection and patient-level provenance have not been established. High scores on these patterns do not establish performance on real patients.

Read the source comparisons and evidence status.

Health information

Condition descriptions link to MedlinePlus, the US National Library of Medicine's public health information service. These educational summaries have not undergone clinical review for this project. The demo does not provide prescriptions, medication rankings, or personalized diet and exercise plans.
